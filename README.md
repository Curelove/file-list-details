# 文件列表备注

在 Obsidian 原生文件管理器中显示笔记的修改时间、笔记属性值或自定义备注。

插件直接增强 Obsidian 左侧原生文件列表，不会创建新的文件浏览页面，也不会替换 Obsidian 原有的文件管理器。

## 功能

- 显示笔记文件的修改时间。
- 显示笔记顶部属性区域中的属性值。
- 显示自定义文字或备注。
- 同时显示修改时间和指定属性值。
- 可选择显示位置：
  - 自动判断位置。
  - 永远显示在标题右侧。
  - 永远显示在标题下方。
- 可按笔记属性筛选，只对符合条件的笔记显示内容。
- 支持在自定义文字中插入笔记名称、路径、属性值和时间。
- 使用 Obsidian 原生文件列表，不创建独立文件浏览页面。

## 隐私与数据

本插件：

- 不发送网络请求。
- 不收集使用数据。
- 不包含广告。
- 不要求注册账号。
- 不读取库外文件。
- 不会修改笔记正文。
- 不会写入 YAML、Properties 或 frontmatter。
- 不会向其他服务上传笔记内容或笔记属性。

插件仅在当前 Obsidian 库内读取文件修改时间和已有的笔记属性，用于在文件列表中显示内容。

## 安装方法

### 在 Obsidian 社区插件中安装

社区插件审核通过后，可以按以下步骤安装：

1. 打开 Obsidian 设置。
2. 进入“第三方插件”。
3. 搜索“文件列表备注”。
4. 点击“安装”。
5. 安装完成后开启插件。

### 手动安装

1. 从本仓库的 Releases 页面下载最新版中的以下三个文件：

   ```text
   main.js
   manifest.json
   styles.css
   ```

2. 在 Obsidian 库中创建插件目录：

   ```text
   .obsidian/plugins/file-list-details
   ```

3. 将下载的三个文件直接放入该目录。
4. 重启 Obsidian，或在“第三方插件”页面重新加载插件。
5. 在“设置 > 第三方插件”中开启“文件列表备注”。

## 使用方法

安装并启用后，打开：

```text
设置 > 文件列表备注
```

### 显示修改时间

选择：

```text
显示内容：文件修改时间
显示位置：自动判断
```

当文件列表有足够宽度时，时间显示在标题右侧。空间不足或笔记标题较长时，时间会显示在标题下方。

### 显示笔记属性

假设笔记顶部有以下属性：

```yaml
---
status: 进行中
---
```

在插件设置中选择：

```text
显示内容：笔记属性值
属性名称：status
```

文件列表中将显示：

```text
进行中
```

### 同时显示时间和属性

选择：

```text
显示内容：修改时间 + 笔记属性值
属性名称：status
显示位置：永远显示在标题下方
```

文件列表效果类似：

```text
项目计划
10-13 20:45 · 进行中
```

### 自定义显示文字

选择“自定义文字”后，可以填写固定文字，也可以使用变量。

例如填写：

```text
状态：{property}
```

当笔记中有：

```yaml
---
status: 已完成
---
```

文件列表将显示：

```text
状态：已完成
```

支持的变量：

| 变量 | 显示内容 |
| --- | --- |
| `{name}` | 笔记名称，不含 `.md` 后缀 |
| `{path}` | 笔记在库中的路径 |
| `{property}` | 指定属性名称对应的属性值 |
| `{date}` | 文件修改日期 |
| `{time}` | 文件修改时间 |

示例：

```text
{name} · {date} {time}
```

### 按条件显示

可以设置只对部分笔记显示备注。

例如，仅对 `status` 属性值为“进行中”的笔记显示内容：

```text
显示条件：属性值等于指定文字的笔记
条件属性名称：status
条件属性值：进行中
```

对应的笔记属性示例：

```yaml
---
status: 进行中
---
```

## 兼容性

- 已使用 Obsidian 1.13.7 测试。
- 本插件依赖 Obsidian 原生文件列表的内部 DOM 结构。
- 若 Obsidian 后续更改文件列表结构，插件可能需要更新以保持兼容。
